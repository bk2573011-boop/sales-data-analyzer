# 📊 Sales Data Analyzer

Created by Bibha Kumari

A Python project that reads sales data from a CSV file and analyzes it — calculating total sales, product-wise sales breakdown, and the top-selling product.

## ✨ Features
- Reads sales data from a CSV file
- Calculates total number of records and total sales
- Shows sales grouped by product
- Identifies the top-selling product

## 🚀 How to Run

Repository clone karo:

    git clone https://github.com/bk2573011-boop/sales-data-analyzer.git

Folder mein jao:

    cd sales-data-analyzer

Program run karo:

    python main.py
